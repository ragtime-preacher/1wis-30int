# 1wis-30int
A pretty clever codename (if you ask me) for my endeavor to write a terminal-based dnd character builder/handler.

## Desired Features
Ideally, it will include commands to create a character, track limited-use abilities, refill stuff on short/long rests, handle hit die, and spell preparation/learning.

probably some fun colors and whatnot. Some feature to roll dice and add the appropriate modifiers would also be cool, but I personally prefer to roll physical dice and therefore probably won't bother to impliment digital dice (or at least not again, see https://github.com/jack-mcginty/corrosion-dice).

Because of my irrational desire not to get sued, I'll include in the public repository only the subclass and spell options included in the (D&D 5e SRD)[https://media.wizards.com/2016/downloads/DND/SRD-OGL_V5.1.pdf]. For my own personal use, I'll include all the content that I legally own (although some of it might be in portuguese), and I'll write a page on how to write up json files for your own content.
